# Skripsi Structure — Nykripsi v2

Spec for the STMIK Triguna Dharma (TGD) *Hubungan Internasional* skripsi skeleton.
This is a concise structural reference, **not** a copy of the chapter prose.
The skeleton is generated by
[`scripts/scaffold.py`](../scripts/scaffold.py) (default `--out content/skripsi`).

Authoritative layout/typography/register rules live in
[docs/skripsi-pedoman.md](../../../docs/skripsi-pedoman.md). The skripsi → Sinta
article conversion is specified in
[docs/conversion-skripsi-to-article.md](../../../docs/conversion-skripsi-to-article.md).

## Formula-id markers

Each formula-bearing section carries two HTML comments on the same line as its
opening sentence:

```markdown
Penelitian ini bertujuan untuk … <!-- TODO: isi tujuan --> <!-- kamus:f id=tujuan -->
```

- `<!-- TODO: … -->` — a fill-in placeholder.
- `<!-- kamus:f id=<formula-id> -->` — binds the section to a `formula:` entry in
  [`assets/bahasa/kamus-id.yaml`](../../../assets/bahasa/kamus-id.yaml). All ids
  used above are keys of that file's `formula:` map; `scaffold.py` emits exactly
  this set.

## Register rules (summary)

Body chapters use the Indonesian academic register (same rules as the article —
see [docs/bahasa-artikel.md](../../../docs/bahasa-artikel.md) and
[docs/kamus-bahasa-artikel.md](../../../docs/kamus-bahasa-artikel.md)):

- **No first/second-person pronouns** (`saya`, `aku`, `kami`, `kita`, `anda`,
  `kamu`, `kalian`) in body chapters; prefer passive (`dilakukan`, `digunakan`,
  `dikumpulkan`, `dianalisis`). `penulis`/`peneliti` are allowed as impersonal
  self-reference.
- **Baku diction (EYD Edisi V)**: `analisa→analisis`, `praktek→praktik`,
  `merubah→mengubah`, `aktifitas→aktivitas`, `hipotesa→hipotesis`,
  `sistim→sistem`, `standard→standar`, `jadual→jadwal`, `obyek→objek`,
  `metoda→metode`.
- **Exemption**: `03-surat-pernyataan.md` is a personal legal declaration
  (`karya saya sendiri`) and legitimately uses first person.

`make check` runs the register linter over the body chapters and the article.
